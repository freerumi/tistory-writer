# 티스토리 글 작성

입력 예: `/tistory-post 상강 / 상강 뜻 유래 풍속 / 2026 상강 날짜, 상강 음식`

## 작업 순서

1. **주제 분류**: 절기·생활정보 / 스포츠 / 영화 중 하나로 정한다. 애매하면 가장 가까운 템플릿을 고른다.
2. **상위 노출 글 분석 (필수, 글쓰기 전에)**
   - 다음(Daum) 통합검색의 **블로그 탭**에서 메인 키워드를 검색한다: `https://search.daum.net/search?w=blog&q=<메인 키워드>`
   - 광고를 뺀 **1위 블로그 글**의 URL을 확인한다.
   - 셀 단어 목록을 정한다. 스크립트가 메인 키워드의 띄어쓰기 단위 조합(제네시스 챔피언십 우승상금 → 제네시스 챔피언십, 챔피언십 우승상금, 제네시스, 챔피언십, 우승상금)을 자동으로 만든다. 붙어 있는 합성어에서 나온 검색어(우승상금 → 우승, 상금)는 `--extra`로 직접 넣는다.
   - 스크립트로 센다. 직접 세지 않는다. (윈도우에서는 `python3` 대신 `python`으로 실행한다.)
     ```
     python3 tools/keyword_count.py "<메인 키워드>" "<1위 글 URL>" --extra 우승,상금
     ```
   - 결과에서 단어별 **목표 범위(상위 글 +1 ~ +5)**와 **사진 목표(상위 글 +1장 이상)**를 기록한다.
   - 검색이나 글 접속이 막히면 사용자에게 1위 글 URL이나 브라우저에서 저장한 .html 파일을 달라고 한다. 수치를 추측하지 않는다.
3. **자료 조사 (필수)**: 웹 검색으로 사실을 확인한다. 기억에 의존하지 않는다.
   - 오늘 날짜를 기준으로 가장 최신 정보를 쓴다 (경기 결과, 순위, 방영 일정, 상금, 환율).
   - 숫자·날짜·인명은 두 곳 이상에서 교차 확인한다. 확인 못 한 정보는 쓰지 않는다.
   - 절기 날짜·시각은 한국천문연구원(KASI) 월력요항, 낱말 풀이는 국립국어원 표준국어대사전을 기준으로 한다.
   - 영화는 TV 방영 정보(채널, 날짜, 시간)를 확인해 도입부에 넣는다.
4. **HTML 작성**: 아래 규칙을 모두 지켜 `posts/YYYY-MM-DD-<영문-slug>.html`로 저장한다. 2단계의 목표 범위를 맞추도록 키워드를 배치하되, 같은 문장에 억지로 몰아넣지 말고 섹션 전체에 고르게 나눈다.
5. **키워드 수 맞추기**: 비교 모드로 내 글을 검사한다.
   ```
   python3 tools/keyword_count.py "<메인 키워드>" "<1위 글 URL>" --extra 우승,상금 --compare posts/<파일>.html
   ```
   "부족"이나 "초과"가 하나라도 있으면 문장을 고쳐 다시 검사한다. 모든 단어가 OK가 될 때까지 반복한다.
6. **검수와 보고**: 아래 체크리스트를 확인한 뒤, 사용자에게 다음을 알려준다.
   - 분석한 1위 글 URL
   - 키워드 비교표 (단어 / 상위 글 / 내 글 / 판정), 비교 모드 출력을 그대로 보여준다
   - **넣어야 할 사진 수**: 상위 글 사진 N장 → "사진 N+1장 이상 넣으세요"
   - 추천 글 제목 3개 (메인 키워드로 시작, 30~40자)
   - 태그 10개 (쉼표 구분)
   - 저장한 파일 경로

참고 예시: `examples/` 폴더의 세 글이 기준 스타일이다. 헷갈리면 해당 주제 예시를 먼저 읽는다.

## 글 구조 (모든 주제 공통)

1. **요약 문단** 1개: 메인 키워드로 시작, 글에서 다루는 내용을 2문장으로 요약 (검색 설명문 역할).
2. **도입 문단** 2~3개: 공감 가는 상황 → 핵심 답(정의·숫자·날짜) → "하나씩 살펴보겠습니다" 식의 예고.
3. **핵심 정보 박스**: 제목 "한눈에 보는 ○○ 핵심 정보", 항목 5~6개.
4. **목차**: `h2` "목차" + 앵커 링크 목록.
5. **본문 섹션** 7~9개: 각 `h2` 아래 `h3` 1~2개, 필요한 곳에 표·목록.
6. **자주 묻는 질문 (FAQ)**: 질문 4개. 질문마다 메인 키워드를 그대로 넣는다.
7. **마무리**: `h2` 제목을 "○○ 한눈에 정리" 또는 "마무리"로 두고 문단 2개. 메인 키워드로 요약, 행동 권유, 필요하면 출처 명시.

이미지 자리, 광고 자리 표시는 넣지 않는다. 사용자가 직접 넣는다.

## 주제별 섹션 구성

**절기·생활정보**: ○○ 뜻(한자 풀이) → 올해 날짜와 시간(앞뒤 절기 표) → 3후로 보는 유래 → 관련 의례·역사 → 속담 → 풍속 음식 → 관련 개념 풀이 → FAQ → 한눈에 정리(출처)

**스포츠 대회**: 검색 의도의 핵심 답(예: 우승상금, 원화 환산 표) → 그 밖의 혜택·규정 → 역대 우승자 표 → 현재 순위·대진 표 → 시즌 레이스·관련 기록 → 대회 기본 정보와 중계 표 → FAQ → 마무리(다음 일정 안내)

**영화**: 영화 정보 한눈에 보기(기본 정보 표) → 제목 뜻 → 주요 출연진 목록 → 줄거리(결말 전까지) → 결말(스포일러 경고 박스로 시작) → 결말 해석 → 원작·실화와 차이 표 → 흥행 성적과 추천 대상 → FAQ → 마무리

## 키워드 규칙

- 메인 키워드를 요약 문단 첫머리, 도입부, `h2` 제목 2~3개, FAQ 질문, 마무리 첫 문장에 넣는다.
- `h2` 제목에 메인 키워드를 반복할 때 "①", "②"로 구분해도 된다 (예: "상강 뜻 유래 풍속 ①: 3후로 보는 유래").
- 보조 키워드는 `h3` 제목과 본문에 자연스럽게 녹인다. 억지 반복은 하지 않는다.

## 문체

- 존댓말. "~습니다", "~죠", "~거든요", "~예요"를 섞어 대화하듯 쓴다. 영화 글은 "~요" 비중을 높여 더 부드럽게 쓴다.
- 문단은 2~3문장. 한 문장에 정보 하나.
- 이모지, 느낌표 남발, "~에 대해 알아보겠습니다" 같은 상투어 금지.
- 날짜는 요일을 붙인다: `10월 23일(금)`. 금액은 원화를 함께 쓴다: `68만 달러(약 9억 5,000만 원)`.
- 외국 인명·작품명은 처음 한 번만 원어를 괄호로 병기한다: `톰 클랜시(Tom Clancy)`. 작품명은 《》.
- 기준 시점이 있는 정보(순위, 환율)는 "10월 23일 기준"처럼 시점을 밝힌다.

## HTML 규칙

- 출력은 티스토리 HTML 모드에 붙여넣을 **본문 조각만**. `<html>`, `<head>`, `<body>`, `<style>`, `<h1>` 금지 (제목은 티스토리 제목란에 따로 입력).
- 굵게는 `<b>`로 통일. 마크다운 문법 금지.
- 섹션 앵커는 `section1`부터 순서대로, 목차와 정확히 일치시킨다.

### 문단·제목

```html
<p data-ke-size="size18">문단</p>
<h2 id="section1" data-ke-size="size26">섹션 제목</h2>
<h3 data-ke-size="size23">소제목</h3>
```

### 핵심 정보 박스

```html
<div style="border-left: 4px solid #2563eb; background: #eff6ff; padding: 16px 20px; margin: 24px 0; font-size: 18px; line-height: 1.8;">
<p data-ke-size="size18"><b>한눈에 보는 ○○ 핵심 정보</b></p>
<ul style="margin: 8px 0 0; padding-left: 20px;" data-ke-list-type="disc">
<li>항목</li>
</ul>
</div>
```

### 목차

```html
<h2 data-ke-size="size26">목차</h2>
<ul style="font-size: 18px; line-height: 1.9;" data-ke-list-type="disc">
<li><a href="#section1">섹션 제목</a></li>
</ul>
```

### 표 (헤더 파랑, 줄무늬 흰색/연파랑 번갈아)

```html
<table style="width: 100%; border-collapse: collapse; font-size: 18px;">
<thead>
<tr style="background: #2563eb; color: #ffffff; text-align: center;">
<th style="padding: 10px;">항목</th>
<th style="padding: 10px;">내용</th>
</tr>
</thead>
<tbody>
<tr style="background: #ffffff; text-align: center;">
<td style="padding: 10px;">홀수 줄</td>
<td style="padding: 10px;">…</td>
</tr>
<tr style="background: #eff6ff; text-align: center;">
<td style="padding: 10px;">짝수 줄</td>
<td style="padding: 10px;">…</td>
</tr>
</tbody>
</table>
```

### 목록

```html
<ul style="font-size: 18px; line-height: 1.9;" data-ke-list-type="disc">
<li>용어: 설명</li>
</ul>
```

### 안내 박스 (스포일러 경고 등)

```html
<div style="border-left: 4px solid #2563eb; background: #eff6ff; padding: 16px 20px; margin: 24px 0; font-size: 18px; line-height: 1.8;">아래부터는 결말이 모두 나와요. 아직 안 보신 분은 ○○ 파트로 건너뛰셔도 됩니다.</div>
```

### FAQ

```html
<h2 id="sectionN" data-ke-size="size26">자주 묻는 질문 (FAQ)</h2>
<p data-ke-size="size18"><b>Q. 메인 키워드가 들어간 질문?</b></p>
<p data-ke-size="size18">A. 한두 문장 답변.</p>
```

## 검수 체크리스트

- [ ] 비교 모드에서 모든 키워드가 OK (상위 글 +1 ~ +5)
- [ ] 넣어야 할 사진 수를 사용자에게 알렸다
- [ ] 모든 숫자·날짜·인명을 웹 검색으로 확인했다
- [ ] 요약 문단이 메인 키워드로 시작한다
- [ ] 목차 링크와 `h2 id`가 모두 일치한다
- [ ] 표 줄무늬가 흰색/연파랑으로 번갈아 나온다
- [ ] FAQ 4개, 질문마다 메인 키워드 포함
- [ ] `<b>`만 사용, 이모지·이미지·광고 자리 없음
- [ ] 본문 분량은 상위 글 이상 (최소 약 4,000자)
