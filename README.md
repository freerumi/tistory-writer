# tistory-writer

주제와 키워드를 넣으면 티스토리 HTML 모드에 바로 붙여넣을 글을 만들어 줍니다.
Claude Code에서 웹 검색으로 최신 정보를 확인한 뒤 글을 쓰므로 API 키가 필요 없습니다.

## 사용법

Claude Code(웹·앱·터미널)에서 이 저장소를 열고 입력합니다.

```
/tistory-post <주제> / <메인 키워드> [/ 보조 키워드...]
```

예시

```
/tistory-post 상강 / 상강 뜻 유래 풍속 / 2026 상강 날짜, 상강 음식
/tistory-post 제네시스 챔피언십 / 제네시스 챔피언십 우승상금
/tistory-post 썸 오브 올 피어스 / 영화 썸 오브 올 피어스 결말 / OCN 방영
```

진행 순서

1. 다음 블로그 검색 1위 글을 찾아 키워드별 등장 횟수와 사진 수를 셉니다.
2. 내 글의 키워드를 1위 글보다 1~5개 많게 맞춰 작성합니다.
3. 결과물을 `posts/YYYY-MM-DD-slug.html`에 저장하고 키워드 비교표, 넣어야 할 사진 수, 추천 제목 3개, 태그 10개를 알려줍니다.

## 키워드 세기 스크립트만 쓰기

```
# 1위 글 분석
python3 tools/keyword_count.py "제네시스 챔피언십 우승상금" https://xxx.tistory.com/123 --extra 우승,상금

# 내 글과 비교
python3 tools/keyword_count.py "제네시스 챔피언십 우승상금" https://xxx.tistory.com/123 --extra 우승,상금 --compare posts/내글.html
```

- 메인 키워드의 띄어쓰기 단위 조합은 자동으로 셉니다. `우승상금 → 우승, 상금`처럼 붙은 단어를 쪼갠 검색어는 `--extra`로 넣습니다.
- 붙여 쓴 형태(`제네시스챔피언십`)도 같은 키워드로 셉니다. 짧은 단어는 긴 단어 안에 든 것까지 셉니다.
- 사진은 본문 안의 이미지만 셉니다. 이모티콘·스티커, 블로그 로고는 뺍니다.
- URL 대신 브라우저에서 저장한 `.html` 파일을 넣어도 됩니다.

## 티스토리에 올리기

1. 글쓰기 화면 오른쪽 위 `기본모드` → `HTML`로 전환
2. 생성된 HTML 전체를 붙여넣기
3. 제목·태그·카테고리 입력, 이미지와 광고 삽입
4. 발행 또는 예약 발행

## 구성

- `.claude/skills/tistory-post/SKILL.md`: 글 구조, 문체, HTML 서식 규칙
- `examples/`: 스타일 기준이 되는 예시 글 (절기, 스포츠, 영화)
- `posts/`: 생성된 글
